这个插件通过亚马逊的 Ads API 把 cx 连接到你自己的亚马逊广告。连接店铺后，cx 可以读取你的广告活动、广告组、关键词、预算和报告，也能在你授权的站点更新广告，比如提高预算、暂停关键词。

你可以这样问：

- 最近 7 天，我的每个广告活动花了多少、卖了多少？
- 哪些广告活动的预算不够用？
- 哪些关键词只花钱不出单？

## 连接店铺

打开插件的「设置」，为你投放广告的每个区域连接一个店铺：北美、欧洲或远东。「设置」里要填写你的 Ads API 应用信息和刷新令牌，获取方法见亚马逊的授权指南。你的密钥保存在 ComChatX，不会交给 cx。

## 费用

免费。亚马逊和 ComChatX 都不对 Ads API 调用收费。广告本身的花费由你和亚马逊结算。

## 依赖

它会和 cx-sources 一起安装，cx 通过 cx-sources 使用所有数据源。
