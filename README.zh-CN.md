cx 会查看每个广告活动的花费、销售额和 ACOS，把不出单的搜索词设为否定关键词，也能参考亚马逊推荐的关键词和竞价，替你创建广告活动。数据来自亚马逊 Ads API，覆盖商品推广、品牌推广和展示型推广。

你可以这样问：

- B0EXAMPLE1 的广告里，哪些搜索词出了单？
- 给 B0EXAMPLE1 建一个自动投放的商品推广活动，每天预算 20 美元。
- 上个月商品推广和品牌推广的 ACOS 各是多少？

## 连接店铺

在插件的「设置」里，为你投放广告的北美、欧洲或远东区域各连接一个店铺。要填的 Ads API 应用信息和 Refresh token，获取方法见亚马逊的授权指南。你的密钥保存在 ComChatX，不会交给 cx。

## 费用

免费，亚马逊和 ComChatX 都不收费。广告本身的花费由你和亚马逊结算。

## 需要

它会和 cx-sources 一起安装，cx 通过 cx-sources 使用所有数据源。
